# Vocabulario C2

Aplicación estática para practicar sustituciones léxicas de nivel C2 en español.

## Publicación rápida

Puedes subir estos archivos a un repositorio público y activar GitHub Pages desde
`Settings > Pages`. Selecciona la rama principal y la carpeta raíz del proyecto.

La app no necesita backend ni instalación de dependencias. El banco de datos está en
`data/frases-c2.js` y se carga directamente desde `index.html`.

## Estructura

- `index.html`: estructura de la interfaz.
- `styles.css`: diseño responsive.
- `app.js`: lógica de sesión, progreso, filtros y corrección.
- `data/frases-c2.js`: banco de 1000 frases C2.
